# Последний сигнал — прототип 0.6

Кооперативный хоррор от первого лица для **Windows, Linux и macOS**, Godot **4.7.2 Standard**. 2–4 игрока через ENet в одной сети; есть одиночный учебный режим.

Станция разделена на четыре сектора и 24 помещения. Новые задачи: давление в котельной, электрическая схема, сменный фильтр, токсичный архив и настройка частоты. Новая модель сущности Bento с ходьбой, бегом на четвереньках и падением; прежняя сохранена. Звуки включают настоящие записи. [Изменения](docs/ART_UPDATE.md), [авторы ассетов](assets/CREDITS.md).

## Скачать и запустить

1. Скачайте **Code → Download ZIP** или клонируйте:

   ```sh
   git clone https://github.com/IR-Full/Horror_Game.git
   cd Horror_Game
   ```

2. Скачайте **Godot 4.7.2 Standard для своей ОС** с [официальной страницы](https://godotengine.org/download/archive/4.7.2-stable/). .NET, Blender, Audacity и Python для игры не нужны. Все модели, текстуры и звуки находятся в репозитории.
3. Распакуйте движок в папку `Godot` рядом с `project.godot`:

| ОС | Пример расположения движка | Запуск |
|---|---|---|
| Windows | `Godot/Godot_v4.7.2-stable_win64.exe` | `StartGame.cmd` |
| Linux | `Godot/Godot_v4.7.2-stable_linux.x86_64` | `sh StartGame.sh` |
| macOS | `Godot/Godot.app` или `/Applications/Godot.app` | `sh StartGame.sh` |

В Linux при необходимости выполните `chmod +x Godot/Godot_v4.7.2-stable_linux.x86_64`. На macOS сначала откройте скачанный Godot через Finder и подтвердите системный диалог. Скрипт не обходит настройки безопасности ОС.

Можно задать полный путь к движку через `GODOT_BIN`. Поддерживаются пробелы и кириллица в пути. `StartEditor.cmd` / `sh StartEditor.sh` открывают редактор. Альтернатива на любой ОС: импортировать `project.godot` в Godot Project Manager и нажать F5. Стартовые скрипты автоматически импортируют новые ресурсы, в том числе после обновления.

Проверка обнаружения движка: `StartGame.cmd --check` или `sh StartGame.sh --check`.

Для обновления закройте игру и выполните **git pull на обоих компьютерах**. Всем участникам нужна **версия 0.6, протокол 6**.

## LAN с братом

1. Подключите компьютеры к одному роутеру через Wi-Fi/Ethernet. ОС могут отличаться.
2. Хост создаёт комнату. В лобби показаны его IPv4; нужен адрес адаптера этой сети, например `192.168.1.10`.
3. Остальные вводят этот IP и тот же UDP-порт, выбирают роли и подключаются до начала раунда.
4. Разрешите Godot входящие соединения в частной сети в брандмауэре хоста. Открывать порт роутера для LAN не требуется. Гостевая сеть с изоляцией устройств мешает подключению.

Хост остаётся до конца; миграции хоста и входа посреди раунда пока нет. Репозиторий передаёт код и обновления; игровая сессия работает на компьютере хоста.

## Управление

Подсказки клавиш слева снизу удалены. Меню Esc не останавливает общий раунд.

| Клавиши по умолчанию | Действие |
|---|---|
| WASD / мышь | Движение / осмотр |
| Shift / Ctrl | Бег / присесть |
| E | Взаимодействие; удерживать для ремонта и поднятия |
| F / M | Фонарь / схема четырёх секторов |
| Q / G / R | Выбрать ячейку / положить / использовать предмет |
| ЛКМ / T | Выстрел / перезарядка |
| V / H | Отвлечь шумом / SOS раз в 15 секунд |
| Esc | Меню, карта, настройки |

Клавиши и кнопки мыши переназначаются в настройках. Графика: быстрая/средняя/высокая; масштаб 3D 50/75/100%. Отдельные громкости музыки, эффектов и фона. Настройки сохраняются локально через `user://`.

## Секторы и победа

Территория примерно **126 × 118 м**, площадь пола **6732 м²**, около 3.5 прежних карт. Четыре сектора физически связаны переходами. Раунд длится до **30 минут**.

1. **A — жилой блок, 12 помещений.** Листок в медпункте 02 подсказывает код сейфа склада 01 с предохранителем. Ключ из шкафчика мастерской 07 открывает топливную клетку склада. Принесите бензин и предохранитель к генератору 03, удерживайте E. Ключ из жилого блока 05 открывает архив 04: найдите кассету. Настройте реле 09 по журналу из лаборатории 10.
2. **B — котельная, 4 помещения.** По схеме B04 выставьте три вентиля: 2, 1, 3.
3. **C — лаборатории, 4 помещения.** На электрическом пульте погасите все девять индикаторов. Нажатие меняет клетку и соседей по кресту; начальная схема случайна и имеет решение. Возьмите фильтр из разблокированного шкафа C04. Принесите его в установку C01 и удерживайте E для очистки. Нужны питание A и давление B. До очистки токсичный архив наносит периодический урон.
4. **D — узел связи, 4 помещения.** После давления и очистки разблокируется шлюз. Подсказка C03 даёт частоту 47.2: выставьте 4, 7, 2 на регуляторах D. Вставьте кассету в передатчик D.
5. Один игрок удерживает щит питания **A06**, другой — передатчик **D**, 12 секунд. В учебном режиме или при единственном живом участнике достаточно передатчика. Условия B/C/D остаются обязательными.

Две вентиляционные точки A дают шумный переход: присядьте и нажмите E. Полноценного свободно проходимого тоннеля пока нет.

## Роли и опасности

Техник быстрее ремонтирует. Медик поднимает за 3 секунды вместо 6. Охотник начинает с дробовиком и одним заряженным патроном. Ещё четыре патрона размещаются случайно. Роли можно повторять, обязательного состава нет. Инвентарь — четыре ячейки внизу по центру.

Сущность активируется через 20 секунд, слышит шум и замечает близкого игрока со всех сторон. В погоне бежит на четвереньках. Фонарь отпугивает на расстоянии, но не защищает в упор. Незапертые двери открывает ударом. После 35 секунд без обнаружения игроков может сломать генератор или вентиляцию. На ремонт есть **02:00** до гибели команды; затем перерыв саботажа 70 секунд.

Дробовик действует до 14 м, не стреляет сквозь стены. Попадание валит сущность на **60 секунд**, затем она встаёт. Повторный выстрел по лежащей срок не продлевает. Перезарядка — 1.7 секунды.

Раненый падает, стонет, под ним растёт кровь. На спасение есть **120 секунд**, SOS доступен каждые 15 секунд. После гибели вещи остаются на полу. Ботинки оставляют отпечатки протектора и переносят кровь после прохода через лужу.

## Платформы и разработка

Общий GDScript без нативных расширений, Compatibility, три пресета экспорта и проверки на трёх ОС в GitHub Actions. Локально проверены Windows, рендер Intel UHD и LAN на 2/4 процессах. Нативные проверки Linux/macOS отмечаются отдельно результатами Actions. Android/iOS, браузер и геймпад в эту настольную версию не входят.

Для готового приложения без редактора установите Godot 4.7.2 export templates и используйте Project → Export. Для запуска исходного проекта они не нужны. [Официальная инструкция](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html).

Это развиваемый прототип: окружение и персонажи пока не фотореалистичны. Нет голосового чата, второго этажа и интернет-матчмейкинга.
