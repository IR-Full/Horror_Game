# Последний сигнал — прототип 0.2

Кооперативный хоррор от первого лица для Windows, Godot 4 Standard, GDScript. Хост и до трёх клиентов подключаются через ENet по локальному IP. Плагины, аккаунты и внешние ассеты для запуска не нужны.

Обновление 0.2: 24 собственные модели из Blender, фактуры стен и пола, оборудование радиостанции, новая сущность, фонарь с рукой, аварийное освещение, стук, шёпот, сердцебиение и короткие ложные силуэты. Подробности и расположение исходников — в [описании оформления](docs/ART_UPDATE.md). При передаче проекта обязательно копируйте папку `assets/`.

## Скачать проект и Godot

Игра разработана и проверена в **Godot 4.7.2 stable, Standard, Windows x86_64**. Версия .NET не требуется. Исполняемый файл движка не включён в Git; скачайте его по официальной ссылке:

- [Godot 4.7.2 — официальная страница версии](https://godotengine.org/download/archive/4.7.2-stable/).
- [Скачать Godot 4.7.2 Standard для Windows x86_64 — ZIP](https://downloads.godotengine.org/?version=4.7.2&flavor=stable&slug=win64.exe.zip&platform=windows.64).

На ПК брата или любом другом компьютере:

1. На странице этого репозитория нажмите **Code → Download ZIP** и распакуйте архив. Либо выполните:

   ```powershell
   git clone https://github.com/IR-Full/Horror_Game.git
   cd Horror_Game
   ```

2. Скачайте Godot по ссылке выше. Создайте рядом с `project.godot` папку `Godot` и распакуйте туда движок: итоговый путь должен быть `Godot/Godot_v4.7.2-stable_win64.exe`. Godot переносимый, отдельный установщик не нужен.
3. Запустите `StartEditor.cmd`. При первом открытии дождитесь импорта моделей и текстур, затем нажмите **F5**.
4. Для следующих запусков можно использовать `StartGame.cmd`. При отсутствии кэша он сначала импортирует ресурсы.

Стартовые файлы также ищут Godot в стандартной папке загрузок текущего пользователя и в PATH. Если движок лежит в другом месте, задайте переменную окружения `GODOT_BIN` с полным путём к EXE либо импортируйте `project.godot` вручную через менеджер проектов Godot.

Для обновления клонированного проекта закройте игру и выполните `git pull`. На обоих компьютерах должна быть одинаковая версия проекта. Blender, Audacity, Python и шаблоны экспорта для обычной игры не требуются.

В репозитории находятся код, сцены, готовые модели и фактуры, исходник Blender, тесты и документация. Кэш `.godot`, локальный Graphify, результаты тестов и движок исключены из Git.

## Как открыть

1. Дважды нажмите **StartEditor.cmd** в этой папке. Он открывает проект в установленном Godot 4.7.2.
2. Дождитесь импорта значка и нажмите **F5**, чтобы запустить главную сцену.
3. Либо запустите **StartGame.cmd**, чтобы сразу открыть игру без редактора.
4. Если Godot перемещён: откройте менеджер проектов Godot → «Импортировать» → выберите `project.godot` в этой папке.

Стартовые `.cmd` автоматически определяют путь к движку; имя пользователя Windows может быть любым.

## Первая игра вдвоём на одном компьютере

1. Запустите игру дважды через `StartGame.cmd`.
2. В первом окне задайте позывной → **Создать комнату**.
3. Во втором окне введите `127.0.0.1`, тот же порт `27840` → **Подключиться по IP**.
4. Первый игрок — техник-разведчик, второй — медик-оператор. Хост нажимает **Начать экспедицию**.
5. Для знакомства с картой доступна кнопка **Учебный запуск одному** в лобби хоста.

Два окна одновременно нагружают ноутбук сильнее одной копии игры. Начните с быстрой графики и масштаба 50–75%.

## Игра на двух или четырёх компьютерах

1. Подключите компьютеры к одной домашней сети, желательно без гостевого Wi-Fi и изоляции клиентов.
2. На каждом компьютере нужны одинаковые файлы проекта и Godot Standard. До экспорта друг может импортировать `project.godot` в своём Godot.
3. Хост создаёт комнату. В лобби отображаются его локальные IPv4-адреса. При нескольких адресах используйте IPv4 адаптера Wi-Fi/Ethernet этой сети; его также показывает `ipconfig`.
4. Друг вводит этот адрес, например `192.168.1.10`, и тот же UDP-порт.
5. Если Windows спросит разрешение, разрешите Godot доступ к вашей **частной сети**. Открывать порты на роутере для LAN не требуется.
6. Подключайте всех до старта: вход в уже запущенный раунд пока отклоняется. Хост остаётся в игре до конца; перенос хоста не реализован.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | Движение / осмотр |
| Shift | Бег; сущность слышит дальше |
| Ctrl | Тихое движение и более низкая камера |
| F | Фонарик |
| E | Поднять предмет / открыть дверь |
| Удерживать E | Ремонт / питание / передача / поднять союзника |
| Q | Следующий предмет инвентаря |
| G | Положить выбранный предмет под ноги |
| R | Использовать выбранную батарейку или аптечку |
| V | Шумовой сигнал, привлекающий сущность; **не голосовой чат** |
| Esc | Полевое меню; сетевой раунд продолжает идти |

Открытые двери закрываются через небольшую светлую кнопку у края дверного проёма: наведитесь на неё и нажмите E. Дверь не закроется, если в проёме стоит игрок.

## Как победить

1. Из начального коридора войдите налево на **склад**. Предохранитель и бензин стоят на полках. Подойдите, наведите прицел и нажмите E. Медик не переносит тяжёлую канистру.
2. Пройдите дальше по коридору: слева **генераторная**. Удерживайте E у генератора с найденными деталями. Бензин и предохранитель можно принести разными игроками. Техник ремонтирует быстрее.
3. В дальнем левом **жилом блоке** лежит ключ. Им откройте **архив** — среднюю правую комнату. Ключ достаточно иметь при себе.
4. Возьмите кассету в архиве и отнесите её к передатчику в дальней правой **радиорубке**. Удерживайте E, чтобы вставить запись.
5. Один игрок удерживает E у **щита питания**, другой — у **передатчика**, примерно 12 секунд одновременно. Напарник может прерываться ради защиты, но прогресс постепенно уменьшается. В учебном режиме и при единственном оставшемся живом игроке достаточно передатчика.

Сущность появляется через 30 секунд. Она слышит бег, двери, генератор и V, видит игроков при прямой видимости, а направленный фонарик на близком расстоянии заставляет её отступить. Закрытая дверь перекрывает ей маршрут и видимость. При нулевом здоровье союзник может поднять вас, удерживая E: медик за 3 секунды, другие за 6. Через минуту без помощи персонаж погибает, его предметы остаются на полу. Если вся команда оглушена, раунд заканчивается сразу. Единственный живой медик получает возможность переносить канистру. Лимит раунда — 15 минут; баланс прохождения пока экспериментальный.

## Что уже работает

- LAN на 2–4 участника, выбор свободной роли, объединённые роли вдвоём.
- Ожидание загрузки всех клиентов, сетевой спавн, движение с коллизиями на хосте.
- Синхронизация персонажей, батареи, здоровья, предметов, дверей, целей и сущности.
- Инвентарь, ограничение слотов, обмен через выкладывание предметов.
- Один генератор, запертый архив, кассета и финал с двумя разными участниками.
- Слух, зрение, патруль, преследование, поиск, атака, отступление от фонаря и редкая смена позиции сущности.
- Оглушение, поднятие, аптечка, победа/поражение, повторный раунд из лобби.
- При отключении игрока его вещи остаются на карте; при уходе хоста клиенты возвращаются в меню.
- Три пресета, масштаб 3D 50/75/100%, чувствительность, громкость, полный экран; настройки сохраняются локально.
- Оригинальные синтезированные звуки, помехи, стук, шёпот, шаги сущности, сердцебиение и мерцание света.
- 24 модели в GLB, исходная библиотека Blender, четыре фактуры, плакаты, окна, трубы, мебель и радиотехника.

## Границы этого прототипа

Это основа для проверки игры с собственным простым оформлением, ещё без финальной озвучки и баланса на 15–30 минут. Здесь одна компактная станция на одном этаже, один генератор и одна кассета. Подвал, вентиляция, прятки в шкафах, полноценные укрытия, рации с голосом, несколько генераторов, уникальные инструменты оператора, скелетная анимация персонажей и полноценное наблюдение после смерти — следующие этапы.

Режим Compatibility выбран для Intel UHD. «Высокая графика» в этом прототипе добавляет обычный туман и тени; объёмный туман и SSR требуют будущего варианта на Forward+. Масштаб влияет на 3D; интерфейс остаётся чётким. Обещаний стабильного FPS на всех устройствах пока нет.

Позицию рассчитывает хост. У клиента есть плавное отображение полученной позиции и мгновенный поворот камеры, но ещё нет предсказания движения и согласования с сервером для большого пинга. Интернет, проброс NAT, миграция хоста и восстановление прежнего персонажа после переподключения не входят в 0.2.
