# Последний сигнал — прототип 0.4

Кооперативный хоррор от первого лица для Windows, Godot 4 Standard, GDScript. Хост и до трёх клиентов подключаются через ENet по локальному IP. Плагины, аккаунты и внешние ассеты для запуска не нужны.

Обновление 0.4: станция расширена до 12 помещений; добавлены охотник с дробовиком, сейф и шкафчики, задача с реле, вентиляционный обход, саботаж оборудования и двухминутные аварии. Переработаны двери, поведение и модель сущности, кровь, падение раненых, инвентарь и настройки. Подробности — в [описании обновления](docs/ART_UPDATE.md).

## Скачать проект и Godot

Игра разработана и проверена в **Godot 4.7.2 stable, Standard, Windows x86_64**. Версия .NET не требуется. Исполняемый файл движка не включён в Git; скачайте его по официальной ссылке:

- [Godot 4.7.2 — официальная страница версии](https://godotengine.org/download/archive/4.7.2-stable/).
- [Скачать Godot 4.7.2 Standard для Windows x86_64 — ZIP](https://downloads.godotengine.org/?version=4.7.2&flavor=stable&slug=win64.exe.zip&platform=windows.64).

На ПК брата или любом другом компьютере:

1. На странице этого репозитория нажмите **Code → Download ZIP** и распакуйте архив. Либо выполните:

   ```powershell
   git clone https://github.com/IR-Full/Horror_Game.git
   cd Horror_Game
   ```

2. Скачайте Godot по ссылке выше. Создайте рядом с `project.godot` папку `Godot` и распакуйте туда движок: итоговый путь должен быть `Godot/Godot_v4.7.2-stable_win64.exe`. Godot переносимый, отдельный установщик не нужен.
3. Запустите `StartEditor.cmd`. При первом открытии дождитесь импорта моделей и текстур, затем нажмите **F5**.
4. Для следующих запусков можно использовать `StartGame.cmd`. При отсутствии кэша он сначала импортирует ресурсы.

Стартовые файлы также ищут Godot в стандартной папке загрузок текущего пользователя и в PATH. Если движок лежит в другом месте, задайте переменную окружения `GODOT_BIN` с полным путём к EXE либо импортируйте `project.godot` вручную через менеджер проектов Godot.

Для обновления клонированного проекта закройте игру и выполните `git pull`. На обоих компьютерах должна быть одинаковая версия проекта. Blender, Audacity, Python и шаблоны экспорта для обычной игры не требуются.

В репозитории находятся код, сцены, готовые модели и фактуры, исходник Blender, тесты и документация. Кэш `.godot`, локальный Graphify, результаты тестов и движок исключены из Git.

## Как открыть

1. Дважды нажмите **StartEditor.cmd** в этой папке. Он открывает проект в установленном Godot 4.7.2.
2. Дождитесь импорта значка и нажмите **F5**, чтобы запустить главную сцену.
3. Либо запустите **StartGame.cmd**, чтобы сразу открыть игру без редактора.
4. Если Godot перемещён: откройте менеджер проектов Godot → «Импортировать» → выберите `project.godot` в этой папке.

Стартовые `.cmd` автоматически определяют путь к движку; имя пользователя Windows может быть любым.

## Первая игра вдвоём на одном компьютере

1. Запустите игру дважды через `StartGame.cmd`.
2. В первом окне задайте позывной → **Создать комнату**.
3. Во втором окне введите `127.0.0.1`, тот же порт `27840` → **Подключиться по IP**.
4. Выберите роли: техник, медик или охотник. Хост нажимает **Начать экспедицию**.
5. Для знакомства с картой доступна кнопка **Учебный запуск одному** в лобби хоста.

Два окна одновременно нагружают ноутбук сильнее одной копии игры. Начните с быстрой графики и масштаба 50–75%.

## Игра на двух или четырёх компьютерах

1. Подключите компьютеры к одной домашней сети, желательно без гостевого Wi-Fi и изоляции клиентов.
2. На каждом компьютере нужны одинаковые файлы проекта и Godot Standard. До экспорта друг может импортировать `project.godot` в своём Godot.
3. Хост создаёт комнату. В лобби отображаются его локальные IPv4-адреса. При нескольких адресах используйте IPv4 адаптера Wi-Fi/Ethernet этой сети; его также показывает `ipconfig`.
4. Друг вводит этот адрес, например `192.168.1.10`, и тот же UDP-порт.
5. Если Windows спросит разрешение, разрешите Godot доступ к вашей **частной сети**. Открывать порты на роутере для LAN не требуется.
6. Подключайте всех до старта: вход в уже запущенный раунд пока отклоняется. Хост остаётся в игре до конца; перенос хоста не реализован.

## Управление

| Клавиша по умолчанию | Действие |
|---|---|
| WASD / мышь | Движение / осмотр |
| Shift / Ctrl | Бежать / присесть |
| E | Взаимодействие; удерживать для ремонта, передачи и поднятия |
| F | Фонарь |
| Q | Следующая ячейка инвентаря |
| G / R | Положить / использовать выбранный предмет |
| ЛКМ / T | Выстрел / перезарядка дробовика |
| V | Отвлечь сущность шумом |
| H | SOS раненого; один раз в 15 секунд |
| Esc | Модальное меню и настройки; раунд продолжает идти |

Клавиши и кнопки мыши переназначаются через **Esc → Настройки → Управление**. Esc остаётся кнопкой меню. Во вкладке аудио отдельно регулируются общая громкость, музыка, эффекты и фон станции. Графика: быстрая, средняя, высокая; масштаб 3D 50/75/100%.

## Роли

Техник быстрее ремонтирует оборудование. Медик поднимает раненого за 3 секунды, остальные — за 6. Охотник начинает с дробовиком и **одним заряженным патроном**. Ещё четыре отдельных патрона появляются в случайных местах из восьми возможных; их расположение выбирает хост заново каждый раунд.

Все три роли доступны и вдвоём. Можно повторять роли; обязательного состава нет. Название роли одинаково в лобби, данных персонажа и HUD. Все могут переносить канистру, решать задачи и ремонтировать системы.

## Как победить

1. Осмотрите **медпункт, сектор 02**: на столе лежит листок кладовщика с подсказкой к сейфу на складе. В сейфе заперт предохранитель.
2. Найдите **мастерскую, сектор 07**, в северном крыле. Откройте шкафчик и возьмите служебный ключ: он открывает топливную клетку на **складе 01**.
3. Принесите бензин и предохранитель к **генератору 03**, удерживайте E. Детали могут принести разные участники.
4. В шкафчике **жилого блока 05** найдите ключ архива. Откройте **архив 04**, осмотрите его шкаф и возьмите кассету. Вставьте её в передатчик **радиорубки 06**.
5. Прочтите журнал электрика в **лаборатории 10**. Настройте три переключателя в **релейной 09** по схеме из журнала.
6. Один игрок удерживает E у щита питания, другой — у передатчика 12 секунд одновременно. В учебном режиме или при единственном живом участнике достаточно передатчика.

Станция занимает примерно **30 × 64 м**, имеет 12 помещений и центральный коридор. Северное крыло: мастерская 07, карантин 08, релейная 09, лаборатория 10, насосная 11, холодильник 12. Вентиляционные люки в карантине и насосной дают шумный короткий путь: присядьте и нажмите E. Переход выполняется между двумя точками, отдельного свободно проходимого тоннеля пока нет.

## Сущность и аварии

Сущность начинает действовать через 20 секунд. Она слышит бег, двери, выстрелы и шумовые сигналы; замечает близкого игрока со всех сторон. Фонарь может отпугнуть её на расстоянии, но не защищает в упор. При погоне она опускается на четвереньки. Незапертую закрытую дверь открывает ударом, сохраняя физические коллизии. Архив остаётся заперт до нахождения ключа.

Периодически сущность рычит, кричит и бьёт по полу. После 35 секунд без обнаружения игроков может пойти к оборудованию и ударом вывести из строя генератор или вентиляцию. После саботажа действует перерыв 70 секунд; одновременно возможна одна авария.

На экране появляется общий отсчёт **02:00 до гибели**. При отказе генератора останавливаются питание и отопление; при отказе вентиляции заканчивается запас кислорода. Удерживайте E у повреждённого устройства: обычный ремонт занимает 8 секунд, у техника быстрее. Новые детали не нужны. До ремонта передать сигнал нельзя. Если срок истёк, команда проигрывает.

Дробовик действует до 14 м и не стреляет через стены или двери. Попадание валит сущность: она остаётся лежать **60 секунд**, затем поднимается. Повторный выстрел по уже лежащей сущности не продлевает этот срок. Заряд одиночный, перезарядка занимает 1.7 секунды.

При нулевом здоровье персонаж падает и лежит, стонет, под ним постепенно растекается кровь. На спасение есть **120 секунд**. H передаёт SOS с позывным; пауза между вызовами — 15 секунд. После поднятия кровотечение прекращается. При окончательной гибели вещи остаются на полу. Раунд не заканчивается мгновенно, пока все лишь ранены: продолжается отсчёт до окончательной гибели. Общий лимит экспедиции — 15 минут.

## Оформление и ограничения

В проекте 39 собственных моделей Blender, восемь наборов фактур 512×512 и процедурные материалы крови и мышц. Сущность имеет 15 костей и 11 анимаций, включая отдельные падения из вертикальной и низкой стойки. У предметов скруглены края, добавлены фактуры дерева и ткани. Исходная библиотека — `art-source/station_assets.blend`; для игры Blender не нужен.

Это развиваемый прототип с процедурным оформлением. Освещение и материалы стали подробнее, но фотореализм и полноценные анимации всех суставов игроков пока не достигнуты. Нет голосового чата, второго этажа, миграции хоста, сетевого предсказания движения и интернет-матчмейкинга. Вентиляционный обход представлен переходом между люками. Для Intel UHD оставлен Compatibility; объёмный туман и SSR не используются.

Оба компьютера должны получить **одну версию 0.4**: схема синхронизации обновилась и со старыми клиентами несовместима. Закройте игру и выполните `git pull` на каждом клонированном проекте.
