# Ассеты «Последнего сигнала»

Все модели и текстуры в этой папке созданы специально для данного проекта. Сторонние модели, текстуры, записи и платные ассеты не использовались.

- `models/*.glb`: 24 модели, созданные скриптом `tools/build_art.py` в Blender 5.2.3 LTS. Суммарно 8 604 треугольника в каталоге уникальных моделей; число отрисовываемых треугольников зависит от повторений на карте.
- `models/catalog.json`: перечень моделей и числа треугольников.
- `textures/*.png`: четыре процедурные текстуры 512×512 — штукатурка, краска, бетон, плитка.
- `shaders/atmosphere.gdshader`: лёгкая виньетка, зерно и отклик на угрозу/урон.
- `art-source/station_assets.blend` в корне проекта: редактируемая библиотека моделей. Папка исключена из импорта Godot через `.gdignore`.
- Звуки синтезируются в `scripts/core/audio_manager.gd`. Шёпот представляет собой обработанный шум; записи голоса и микрофон не используются.

Для запуска проекта Blender не нужен: Godot читает готовые GLB. Для повторного создания ассетов используйте Blender с `--background --factory-startup --python tools/build_art.py`.
