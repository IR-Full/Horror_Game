# Аудио 0.10

Текущий банк: **90 OGG, 26 событий**, 54 исходных аудиофайла. Добавлены две актёрские записи дыхания **Joseph SARDIN**, CC0 1.0:

- [Breathless man, 1103](https://bigsoundbank.com/breathless-man-s1103.html) → `assets/audio/sources/sardin_breath_heavy.wav`.
- [Man breathing, 2195](https://bigsoundbank.com/man-breathing-s2195.html) → `assets/audio/sources/sardin_breath_calm.wav`.

Происхождение, лицензии и SHA-256 сохранены в sources.json. `python tools/build_condition_audio.py` создаёт две 12-секундные моно-петли 32 кГц, согласует RMS и сглаживает шов на 150 мс. Выполнять после основной сборки build_audio.py, поскольку она перезаписывает банк. Готовые клипы входят в Git; скачивание во время игры не нужно.

`player_condition.gd` смешивает лёгкое и тяжёлое дыхание по выносливости/стрессу, плавно меняет громкость и темп. Свой звук — 2D, чужой — пространственный до 10 м. Движок воспроизводит его на шине Effects. Смотритель автобазы использует прежние реплики/рычание с множителем pitch 0.84; отдельная актёрская речь ему не приписывается. Остальные источники и инструменты ниже сохранены.

# Аудио 0.9

Текущий банк: **88 OGG, 24 события**. Три SAPI-реплики заменены 18 новыми русскими фразами на мужском нейросетевом голосе **Piper Dmitri medium**. Это синтез, не запись актёра. Сильное понижение высоты, второй голос и модуляция 37 Гц убраны. Остались снижение примерно на один полутон, мягкое насыщение и тихое отражение 75 мс. Хост выбирает одну реплику для всех участников, перебирая все 18 без повторов внутри цикла. Громкость речи в игре повышена с +1 до +4 дБ; крики и остальные игровые записи сохранены.

Модель: [rhasspy/piper-voices / Dmitri](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/dmitri/medium/MODEL_CARD). Карточка указывает **CC0** для датасета, репозиторий модели — MIT. SHA-256 модели и всех 18 WAV, тексты и происхождение сохранены в assets/audio/sources.json. Карточка сохранена рядом с WAV. Прежние три WAV SAPI оставлены в исходниках, но не используются активным банком. Всего сохранено 52 исходных аудиофайла.

Синтез выполняется локально CPU-инструментом Piper только при подготовке ассетов. В игре и экспортированном приложении воспроизводятся готовые OGG: синтезатор, модель ONNX и интернет не нужны. Инструменты и модель исключены из Git, импорта Godot и экспорта через .gdignore/пресеты. Для повторной подготовки:

```sh
python -m pip install piper-tts numpy soundfile
# Скачать ru_RU-dmitri-medium.onnx и .onnx.json в tools/voice-models/
python tools/build_monster_voice.py
python tools/build_audio.py --voices-only
```

build_monster_voice.py временно копирует словарь espeak в путь без кириллицы: его Windows C API не открывает русские пути. Остальной проект сохраняет свой настоящий путь. Piper — инструмент разработки с собственной лицензией GPL-3.0, его код и бинарные файлы в игру не включены. Результаты подготавливаются заранее для всех настольных ОС.

# Аудио 0.7

Новый банк: **73 OGG, 24 события**. Добавлены [боль EmoPreben](https://opengameart.org/content/pain-sounds-by-emopreben) и [обувь по бетону Joseph SARDIN](https://bigsoundbank.com/footsteps-shoe-on-concrete-s0514.html), обе публикации CC0. Фрагменты шагов выделены из настоящей записи, сохранены естественные атака и шорох. Боль сохраняет высоту голоса исполнителя. Звуки Bodycam не копировались.

Три реплики сущности созданы локально голосом Microsoft Irina Desktop / Windows SAPI: «Вы где?», «Я вас найду и убью», «Выходите. Я же всего лишь хочу поиграть с вами». Для эффекта используются пониженная высота, тихий второй слой, насыщение, дыхательная шероховатость, дрожание и короткое эхо. Это синтезированные реплики; они отдельно помечены в sources.json и не приписаны авторам CC0. В готовой игре синтез и интернет не используются: на Windows/Linux/macOS воспроизводятся одни OGG.

Сохранены 34 источника: 31 запись CC0, включая прежний архив, и 3 исходных WAV синтеза. Все SHA-256 и происхождение — в assets/audio/sources.json. Исходники исключены из Godot-импорта и экспорта. bank.json описывает фактически используемые клипы и обработку.

Обработка и сборка — tools/build_audio.py. Для разработки нужны Python, numpy и soundfile; игрокам они не нужны. Для собственного окружения разработчика:

```sh
python -m pip install numpy soundfile
python tools/build_audio.py
```

Рёв и рычание громче предыдущей версии, дальность громких угроз до 80 м, голос слегка глушится за стенами. Отдельная громкость эффектов доступна в настройках. Нормализация файлов сохраняет запас по пику, общий микс регулируется аудиошинами.

## Повторная сборка разработчиком

Игроку ничего устанавливать не нужно. Разработчику нужны Python, numpy и soundfile:

```sh
python -m pip install numpy soundfile
python tools/build_audio.py
```

Затем выполните импорт в Godot. Оригиналы не изменяются. Audacity можно использовать для прослушивания и ручной обработки WAV/OGG. Если хочется заменить звук, положите новый WAV/OGG в отдельную папку assets/audio/custom/, импортируйте и измените соответствующий путь bank.json. Сохраняйте лицензию и автора нового файла. Установка сторонних кодеков для воспроизведения готового OGG не требуется.
